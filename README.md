## Koray Nar

Google Ads audits, AI automation and QA. Rize, Türkiye — remote.

I audit and fix the parts of paid acquisition and automation that fail quietly: a tag that fires
twice or not at all, a workflow step that completes with wrong output, a conversion that stopped
being recorded and looks exactly like a bidding problem.

### Delivered client work

**[WhatsApp Product & Document Assistant](https://koraynar.github.io/research-samples/portfolio/whatsapp-assistant/)**
— a delivered assistant for an aluminium profile manufacturer in Türkiye. It interprets customer
questions, retrieves relevant catalogue information and returns approved documents, combining an LLM
with deterministic safeguards for document access, routing and operating limits. Client identity and
commercial details withheld.

### Independent samples — open source, MIT

- **[doc-extract-mcp](https://github.com/koraynar/doc-extract-mcp)** — MCP server giving an assistant
  deterministic document tooling: PDF/text reading, chunking, JSON Schema validation, structured
  output. Path-confined, fully tested. In the official MCP Registry.
- **[trendyol-seller-mcp](https://github.com/koraynar/trendyol-seller-mcp)** — unofficial MCP server
  for the Trendyol Marketplace seller API. Write operations env-guarded, PII redacted by default.
  In the official MCP Registry.
- **[n8n-ai-workflows](https://github.com/koraynar/n8n-ai-workflows)** — lead intake and
  qualification, Claude-powered email triage, and a de-duplicating job-feed digest, each with a
  headless-executable twin and real run evidence. **The CLI runs mock the model call**, so that
  evidence proves the workflow wiring and output handling, not model quality.
- **[qa-samples](https://github.com/koraynar/qa-samples)** — a test plan, a bug-report template and a
  worked example, showing how I structure findings, evidence and priority.
